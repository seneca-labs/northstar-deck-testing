# North Star Deck · testing

**Open it:** https://seneca-labs.github.io/northstar-deck-testing/

- `index.html`: the menu. Both animations come first, then every board of the deck by section. Click a board to see it full size; arrow keys or swipe page through, and F goes full screen.
- `signin.html`: the sign-in animation, from the form to the welcome title. Tapping the forward ring opens the opening.
- `opening.html`: slides 1, 1.1 and 1.2. Link straight to a slide with `opening.html#1.1`.

The boards are exported from the Paper file "pitch deck", page "final", and converted from Display P3 to sRGB. The opening's photos are the deck's newest, cropped and saturated the way Paper shows them.
